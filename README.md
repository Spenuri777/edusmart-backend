# EduSmart Backend

The backend of the EduSmart platform. It provides the necessary API endpoints to handle school-related data, such as grades, attendance, and schedules, ensuring communication between the database and the frontend application.

### Technologies
- **Language:** PHP (developed as a requirement for a school project)
- **Architecture:** RESTful API
