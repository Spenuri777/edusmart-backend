# EduSmart Backend

The backend component of the EduSmart platform. It provides the necessary API endpoints to handle school-related data, such as grades, attendance, and schedules, ensuring secure communication between the database and the frontend application.

### Technologies
- **Language:** PHP (developed as a requirement for a school project)
- **Architecture:** RESTful API

### Features
- **Authentication:** Secure user login and session handling.
- **Data Management:** Endpoints for retrieving student grades, class schedules, and attendance logs.
- **Data Processing:** Logic for calculating averages and filtering data based on user roles (student/teacher).
